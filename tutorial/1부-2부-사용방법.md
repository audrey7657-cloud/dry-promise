# 1부·2부로 나누어 플레이하기

## 적용 방법

압축 안의 `js`, `data`, `tutorial` 폴더를 기존 게임의 `index.html`이 있는 폴더에 합쳐 덮어쓰세요. 게임을 닫았다가 다시 열고 기존 **새 게임** 버튼을 누르면 부 선택창이 나옵니다. 플러그인 등록도 포함되어 있어 별도 설정은 필요 없습니다.

기존 QTE 조작 설명·연습, 대시 제거, 새 게임 미니맵 ON 설정도 포함했습니다.

## 기존 메뉴와 부 선택

첫 화면의 배경, 새 게임·이어하기·옵션 이미지 버튼, 위치와 마우스를 올렸을 때의 효과는 기존 디자인을 그대로 사용합니다. 이어하기·옵션·저장 화면도 기존 화면을 사용합니다.

**새 게임**을 누를 때만 1부·2부 선택창이 열립니다. 선택창, 1부 완료창, 사본 선택창과 2부 소개창에는 기존 게임의 `Window.png` 금빛 테두리·바탕·선택 표시와 게임 글꼴을 적용했습니다. 선택하지 않은 버튼은 기존 메뉴의 밝은 글자색으로 표시합니다.

| 버튼 | 시작 위치 |
|---|---|
| 새 게임 → 1부 시작 | 프롤로그부터 새로 시작 |
| 새 게임 → 2부 시작 | 1부 완료 기록을 불러와 페메의 첫 취재부터 시작 |
| 부 선택창의 돌아가기 | 기존 첫 화면으로 돌아가기 |
| 이어하기 | 일반 저장 파일을 골라 저장한 장면부터 계속 |
| 옵션 | 기존 게임 설정 |

1부는 비아 추격전과 뒤따르는 대화까지입니다. 비아가 기록을 확인하기로 한 뒤, 방송국의 페메를 소개하기 직전에 완료 화면이 나옵니다. 2부에는 페메의 첫 취재부터 게임의 나머지 이야기가 포함됩니다.

## 1부를 마쳤을 때

선택과 진행 상황을 별도로 저장합니다. 저장을 확인한 뒤 다음 버튼이 나옵니다.

- **오늘은 여기까지:** 처음 화면으로 돌아갑니다. 다음 시간에 **새 게임 → 2부 시작**을 누르세요.
- **2부 바로 시작:** 지난 이야기를 짧게 보고 바로 이어서 합니다.

저장이 실패하면 성공했다고 표시하지 않고 ‘다시 저장’을 보여 줍니다. 이 경우 저장 없이 즉시 2부를 진행하는 것도 가능합니다.

## 완료 기록이 없을 때

**새 게임 → 2부 시작**을 누르면 다음 질문을 보여 줍니다.

> 1부에서 어떻게 했나요?
>
> R-17 사본을 가져갔어요 / 내용만 적고 사본은 제자리에 두었어요

선택에 연결된 비아의 반응과 이전 필수 사건 완료 상태, 확보한 문서, 인물과 첫 취재 목표를 준비한 뒤 방송국에서 시작합니다. 이스메네와 페메가 이후에 할 선택은 원래 장면에서 직접 결정합니다.

완료 기록이 있을 때도 ‘선택 화면으로’를 누르면 다른 선택으로 2부를 새로 시작할 수 있습니다. 이 동작은 보관한 완료 기록을 덮어쓰지 않습니다.

## 기록 보관 방식

최근 1부 완료 기록 한 개를 일반 저장과 따로 보관합니다. 2부 진행 중 일반 저장을 하거나 새 1부를 시작해도 이 기록은 유지됩니다. 새 1부를 끝내고 저장에 성공하면 최근 완료 기록으로 갱신됩니다.

브라우저에서는 같은 기기·브라우저·게임 주소의 저장 공간을 사용합니다. 다른 기기를 쓰거나 기록이 없으면 시작 전 질문으로 들어갈 수 있습니다. 공용 기기에서는 표시된 완료 날짜와 사본 선택을 확인하세요.

## 변경과 검증 범위

`js/plugins/DP_Chapters.js`를 추가하고 `js/plugins.js`에 등록했습니다. 기존 Map030 이벤트 15에서 페메 소개를 시작하기 직전에 멈추며, 다시 시작할 때 원래 이벤트의 다음 장면으로 이어집니다. 이 지점의 이벤트 명령과 후반 이야기의 분기 조건은 수정하지 않았습니다.

Chromium의 터치 환경에서 두 선택의 2부 진입, 실제 방송국 도입과 주민 취재, 완료 기록 저장·복원, 일반 저장·불러오기, 기록 보존, 저장 실패 재시도, 손상 기록 대처, 화면 배치를 검사했습니다. 사본 선택과 이스메네 선택의 네 조합은 원본 이벤트의 조건·상태 명령으로 추가 검사했습니다.

`1부-2부-검증결과.json`은 부 분할 기능을 처음 구현했을 때의 검사 기록입니다. 그때의 첫 화면 구성은 이번 수정으로 대체했습니다. 메뉴 디자인 복원 후 별도로 실행한 터치 조작, 기존 화면 연결, 완료 기록 재개와 화면 배치 검사는 `메뉴디자인-검증결과.json`에 기록했습니다.

검사에서는 긴 대화를 자동으로 넘기고 추격전 종료 분기부터 실행했습니다. 전체 이야기 처음부터 모든 엔딩까지의 수동 플레이와 실물 태블릿 검사는 수행하지 않았습니다.
