# 메마른 약속 · 태블릿 조작 연습

`index.html` 하나에 연습 화면, 원작 장면 9개, 이미지와 조작 안내가 모두 들어 있습니다. 로그인이나 앱 설치, 별도 영상 다운로드가 필요하지 않습니다.

게임 시작 전 안내 연결도 추가했습니다. 적용용 ZIP의 `js`, `data`, `tutorial` 폴더를 기존 게임 폴더에 합치면, 평소처럼 게임을 실행했을 때 QTE 직전에 설명이 나타납니다. 자세한 연결 위치와 검증 내용은 `게임연결.md`에 있습니다.

## 실행

1. `index.html`을 웹 브라우저에서 엽니다. 이미 게임을 웹에 올려 사용한다면 같은 사이트의 `tutorial/index.html` 주소로 접속하면 됩니다.
2. 태블릿을 가로로 놓고 조작을 고릅니다.
3. **천천히 따라 보기 → 직접 연습하기 → 다시 연습 / 다음 조작**으로 진행합니다.

파일 앱의 미리보기는 웹 브라우저와 달라 실행을 지원하지 않을 수 있습니다. 그런 경우 기존 게임 사이트에 이 폴더를 올리고 브라우저로 접속하면 됩니다. 이 작업에서 사이트를 새로 배포하지는 않았습니다.

기본 연습 시간은 원작 설정의 3배입니다. 익숙해지면 **원작 설정 속도**를 고를 수 있습니다. 오른쪽 **●가 결정 버튼**입니다. **원작 장면 보기**로 해당 영상의 실제 성공 장면을 확인할 수 있습니다.

## 포함된 자료

- `index.html`: 실행 파일. 이미지·영상·스크립트 내장, 약 6.4MB.
- `영상분석.md`: 영상 4개의 타임코드, 조작 근거, 유형별 자막·시범 시점, 원작 실패·재시도 처리.
- `검증결과.md`: 입력 및 화면 검증 범위와 남은 한계.
- `검증결과.json`: 자동 검증 기록.
- `게임연결.md`, `게임연결-검증결과.json`: 원작 QTE 시작 전 안내의 적용·검증 자료.

영상에서 확인한 9개 상황을 다룹니다. 같은 방향 순서라도 제한 시간이 다른 경우는 구분했습니다. 원작 전체 게임이나 제한 시간 없는 퍼즐은 포함하지 않습니다.

원본 영상은 PC 화면입니다. 태블릿 입력은 저장소의 실제 화면 버튼과 입력 설정을 대조하고 원작의 터치 실행으로 확인했습니다. 단독 HTML 파일에는 외부 네트워크 요청이 없으며, 웹으로 연 다음 연결을 끊은 상태에서 조작과 내장 영상 재생을 검증했습니다.

게임 연결은 새 플러그인과 플러그인 등록으로 적용했습니다. 원작의 맵 이벤트 데이터와 QTE 판정 코드는 유지했습니다. 게임·영상·이미지의 권리는 원 권리자에게 있습니다.
