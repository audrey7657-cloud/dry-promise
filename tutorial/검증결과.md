# 검증 결과

독립 튜토리얼 검증 기록이다. 이후 추가한 게임 시작 전 연결은 `게임연결.md`와 `게임연결-검증결과.json`을 참조한다. Chromium의 태블릿 터치 환경(Playwright 1.62.1)에서 검사했다. 가상 키보드 입력이나 정답 함수 호출로 성공을 만들지 않고 실제 브라우저 터치 이벤트로 조작했다. 긴 제한 시간 검사는 브라우저 가상 시계로 진행했다.

## 완료한 검사

9개 조작 각각에서 다음 항목을 통과했다.

- 자동 시범이 끝나고 직접 연습으로 이동.
- 느린 연습에서 올바른 입력으로 성공.
- 원작 설정 속도에서 올바른 입력으로 성공.
- 다른 버튼을 누르면 순서가 진행되지 않고 설정에 맞게 시간 차감.
- 잘못된 입력 뒤 시간 초과 시 해당 원인 안내.
- 입력 없이 시간 초과 시 신호가 보이면 바로 누르라는 안내.
- 재시작 시 입력과 시간 초기화. 단일 신호 연습은 실패한 신호부터 재시도.

입력 수명 검사도 통과했다.

- ●를 700ms 누르고 있어도 한 번만 인정. 손을 떼고 다시 누르면 다음 입력으로 인정.
- 길게 누르다 시간이 끝나면 “손을 떼었다가 다시” 안내.
- 버튼 밖으로 손가락 이동, `pointercancel`, 캡처 해제, 화면 이탈 시 누름 상태 해제.
- 브라우저 포커스 이탈, 숨김, 페이지 이탈 시 일시 정지. 재개 시 남은 시간 보존.
- 준비 중 누른 버튼은 정답으로 세지 않고 손을 뗀 뒤 시작.
- 두 손가락이 닿아도 다음 정답이 임의로 처리되지 않으며 모두 떼면 정상 입력 가능.
- 조작 버튼 위에서 두 손가락을 움직여도 페이지 위치와 확대율 유지.
- 터치만으로 9개 조작을 차례대로 성공하고 마지막에 조작 선택 화면으로 돌아오기.

## 화면·영상·독립 실행

- 1280×800, 1024×768, 1180×820, 1024×600 가로 화면에서 게임 장면·안내·버튼이 한 화면에 배치됨.
- 실제 조작 버튼은 원작과 같은 크기 유지. 모두 최소 44 CSS px 이상의 터치 영역.
- 작은 화면과 성공 화면을 이미지로 확인하여 핵심 표시와 버튼이 가려지지 않는지 점검.
- 내장 원본 클립 9개 모두 960×540, 1배속으로 로드·재생 가능. 길이가 지정 구간과 일치.
- HTML을 연 뒤 네트워크를 끊은 상태에서 전체 조작과 내장 영상 검사 통과.
- HTML 최초 요청 이외 외부 HTTP 요청 0건, 브라우저 스크립트 오류 0건.
- JavaScript 구문 검사 통과. 독립 튜토리얼 제작 당시에는 기존 게임 소스 변경 없음.

원작 게임도 별도로 터치 환경에서 실행하여 가상 방향키 입력 성공, ● 길게 누르기 1회 처리, 총 8번 누르고 떼기 성공을 확인했다. 튜토리얼 버튼만 검사한 결과와 구분한다.

## 범위와 한계

물리 태블릿, iPad Safari 및 다른 브라우저에서는 아직 직접 시험하지 않았다. 이 환경의 Chromium은 관리 정책으로 `file://` 열기를 막고 있어 파일 더블클릭 방식 자체는 검증하지 못했다. 대신 HTTP로 HTML 한 파일을 로드한 뒤 완전히 오프라인으로 검사했다. 코드·영상·이미지에는 서버 API나 외부 파일 의존성이 없다.

세부 기록은 `검증결과.json`에 있다. 브라우저 검증 결과를 원작 게임 전체의 검증이나 모든 기기에서의 동작 보장으로 해석하지 않는다.
