# 대시 제거와 새 게임 미니맵 기본값

이 적용본에는 이전 QTE 시작 전 설명·시범·연습 기능도 포함되어 있습니다.

- 대시 기능을 제거했습니다. Shift, 화면 방향키, 목적지 이동, 과거의 '항상 대쉬' 설정으로 가속되지 않습니다.
- 옵션에서 '항상 대쉬' 항목을 제거했습니다. 이벤트에서 지정한 이동 속도는 유지합니다.
- 새 게임을 시작하면 미니맵 옵션이 ON으로 초기화됩니다. 프롤로그가 끝나면 미니맵을 펼쳐 표시합니다.
- 기존 CG 감지와 숨김·복귀 동작을 유지합니다. 수동 접기와 기존 저장 불러오기의 미니맵 상태도 유지합니다.

## 적용

압축 안의 `js`, `data`, `tutorial` 폴더를 기존 게임의 `index.html`이 있는 폴더에 합쳐 덮어씁니다. 플러그인 등록은 포함되어 있으므로 별도로 설정할 필요가 없습니다. 실행 중인 게임은 닫았다가 다시 엽니다.

이번 변경 파일은 다음과 같습니다.

- `js/plugins/DP_GameDefaults.js`: 대시 차단, 옵션 제거, 새 게임 초기화.
- `js/plugins.js`: 위 플러그인 등록, MK_Minimap의 기본 표시값 ON.
- `data/Map001.json`: 프롤로그 종료의 ShowTab 바로 뒤에 Expand 명령 1개 추가.

다른 지도 이벤트와 기존 CG 판별 코드는 변경하지 않았습니다.

## 확인 결과

Chromium에서 원본 게임을 실행해 14개 검사를 통과했습니다. 긴 프롤로그의 대화는 자동으로 넘겼으며, 프롤로그의 원본 이벤트 명령과 CG 표시·해제 명령은 실제로 실행했습니다.

- 기존 미니맵 OFF 설정에서 새 게임 ON 초기화 및 프롤로그 종료 후 실제 표시.
- 프롤로그와 중첩 CG 중 숨김, 마지막 CG 종료 후 복귀.
- 수동 접기 상태 및 일반 대화 중 표시 유지.
- 저장 데이터에 대시 상태가 남아 있어도 가속 차단.
- Shift·기존 항상 대시 ON·목적지 이동·실제 화면 방향키 터치 모두 걷기.
- 이벤트 지정 속도 유지, 옵션 항목 제거, 옵션에서 복귀 후 미니맵 표시.

자세한 결과는 `기본설정-검증결과.json`에 기록했습니다. 실물 태블릿에서의 검사는 수행하지 않았습니다.
