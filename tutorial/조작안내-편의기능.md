# 첫 조작 안내와 편의 버튼

## 적용

수정 ZIP 안의 `js`, `data`, `tutorial` 폴더를 기존 게임의 `index.html`이 있는 폴더에 합쳐 덮어쓰세요. 기존 이미지·음악·글꼴은 그대로 사용합니다. 이전 QTE 안내, 대시 제거, 시작 시 미니맵 ON, 1부·2부 분할도 포함한 누적 수정본입니다.

## 첫 조작 안내

프롤로그 뒤 안티고네의 혼잣말과 ‘부엌 수도를 확인하자’ 목표 메시지가 모두 끝나면, 이동하기 전에 다음 네 장이 나옵니다.

1. 미니맵에서 목표 말풍선을 찾고, 접혀 있으면 장소 이름을 눌러 펼치기
2. 빨간 화살표와 아래쪽 현재 목표를 보고 이동하기
3. 물음표 말풍선과 미니맵 말풍선을 보고 조사할 곳 찾기
4. 방향키로 가까이 가서 대상을 바라본 뒤 ●를 한 번 누르고 떼기

‘이전’과 ‘다음’으로 읽고 마지막에 ‘부엌 수도 확인하러 가기’를 누르면 원래 플레이가 이어집니다. 안내 중에는 맵 진행과 입력을 멈춥니다. 끝까지 읽은 상태는 일반 저장에 보관되어 다시 불러와도 반복되지 않습니다. 이전 버전에서 첫 혼잣말 직후, 수도를 조사하기 전에 저장한 파일에도 안내를 표시합니다. 이미 수도를 조사한 저장이나 2부 시작에는 표시하지 않습니다.

영상 근거는 앞서 받은 V3 `전체 플레이+엔딩 A(XX).mp4`입니다. 01:21–01:42의 프롤로그 마무리·첫 목표·수도 조사·길안내, 08:26–08:50의 물길 기록실 조사 장면, 13:10의 미니맵과 빨간 화살표를 재확인했습니다. 안내에 들어가는 미니맵 예시는 V3 13:10의 실제 화면 일부입니다. 아이콘은 원작 `IconSet.png`의 4번 말풍선, `Balloon.png`의 2번 물음표입니다. 물음표의 조사 용도는 Map004 이벤트 13의 실제 표시 명령으로 추가 확인했습니다. 태블릿 ● 버튼은 PC 영상에서 추정하지 않고 `DP_TouchControls.js`와 실제 터치 실행으로 검증했습니다.

표시 위치는 Map001 이벤트 4의 마지막 메시지 뒤입니다. 해당 이벤트가 끝나고 맵 UI가 갱신된 다음 안내를 열며, 원래 수도 이벤트와 목표 조건은 변경하지 않았습니다.

## QTE 설명과 연습 디자인

QTE 직전 설명, 준비 카운트, 시범·연습과 성공·실패창에 원래 게임의 Window 스킨, 금빛 선택 표시와 게임 글꼴을 적용했습니다. 실제 QTE 표시와 태블릿 방향키·●의 모양은 유지합니다. 연습 화면의 테마와 글꼴도 HTML에 내장하여 단독 실행을 유지합니다.

기존 시범·연습 연결, 입력을 모두 뗀 뒤 시작하는 처리, 잘못 누를 때의 감점과 원작 판정은 유지합니다.

## 기록 조각 퍼즐의 다시 시작

비아·탈로스가 테미스 안내원에게 받는 3×3 기록 조각 퍼즐(Map003 이벤트 9, 두 번째 페이지)의 오른쪽 위에 **다시 시작**을 추가했습니다.

- 현재 시도에서 처음 섞여 나온 배치로 되돌립니다. 새로 무작위로 섞는 기능은 아닙니다.
- 움직인 횟수와 퍼즐 점수를 처음 상태로 되돌립니다.
- 조각이 움직이는 도중 눌러도 이동 애니메이션과 뒤늦은 판정이 남지 않습니다.
- 이야기 선택이나 다른 진행 상태는 변경하지 않으며, 퍼즐 성공으로 처리하지 않습니다.
- 퍼즐을 완성하면 버튼을 숨기고 원래 성공 화면과 후속 이벤트로 이어집니다.

## 옵션 뒤로가기

옵션과 그 안의 오디오 설정 오른쪽 위에 **← 뒤로가기**를 추가했습니다. 오디오에서는 옵션으로, 옵션에서는 열기 전 화면으로 돌아갑니다. 터치 UI 설정이 OFF여도 사용할 수 있습니다. 기존 음량 미리보기 종료와 설정 저장 흐름을 사용합니다.

## 검증 범위

Chromium 터치 에뮬레이션으로 첫 안내 위치, 네 장의 전환과 화면 배치, 실제 ● 수도 조사, 완료 표시의 저장, 옵션·오디오 왕복, 퍼즐 이동 도중 재시작 및 이후 정상 완성을 검사했습니다. QTE는 원래 이벤트 명령에서 설명·연습을 열고 실제 성공·실패 분기로 돌아가는 과정을 검사했습니다. 전체 이야기의 처음부터 끝까지 수동 재플레이와 실물 태블릿 검사는 수행하지 않았습니다. 실행 결과는 `조작안내-편의기능-검증결과.json`에 있습니다.
