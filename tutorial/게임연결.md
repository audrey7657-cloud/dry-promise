# QTE 시작 전 게임방법 안내 적용

적용일: 2026-10-20 (한국 시간)

첨부된 `js.zip`의 43개 파일과 `data.zip`의 52개 파일을 기존 게임과 비교했다. 텍스트 파일의 줄바꿈 형식 차이 외에는 내용이 같았다. 이 파일들을 기준으로 시작 전 안내를 연결했다.

## 플레이 흐름

1. 기존 대화가 끝나고 QTE가 시작될 순간에 해당 조작 설명이 열린다.
2. 목표, 볼 표시, 누를 버튼, 손을 떼는 방법, 제한 시간을 읽는다.
3. 영상에서 확인한 9개 상황에는 **시범·연습 보기**가 있다. 이미 만든 HTML의 해당 조작으로 바로 들어간다.
4. **게임 설명으로 돌아가기**를 누르면 원래 게임의 안내로 돌아온다. 연습의 성공·실패는 게임 결과에 영향을 주지 않는다.
5. **준비됐어요 · 게임 시작**을 누르면 3·2·1 준비 표시 후 원작 QTE가 시작된다. 누르고 있던 손가락이나 키는 먼저 떼어야 한다.

안내와 연습을 보는 동안 맵, 이벤트, QTE 시간은 진행하지 않는다. 준비 중 다른 창으로 이동하면 설명으로 돌아와 다시 준비할 수 있다. QTE 시작 후의 성공 판정, 시간 감점, 실패 분기, 보상과 스토리는 원작 처리를 사용한다.

맵·이벤트·페이지·명령 위치뿐 아니라 실제 버튼 순서, 시간과 감점도 대조해 연결한다. 이후 게임 설정이 바뀌어 일치하지 않으면 다른 상황의 영상을 보여주지 않고 실제 입력 설정으로 짧은 설명을 만든다.

단일 신호 다섯 번은 한 묶음이다. 첫 신호 전에 설명하고, 중간의 네 신호와 해당 신호 재시도 때는 설명을 반복해 흐름을 끊지 않는다. 묶음의 첫 신호로 다시 돌아오면 설명이 다시 열린다.

영상에서 확인하지 못한 다른 Synrec QTE 분기는 실제 시작 함수에 전달되는 방향·횟수·시간으로 설명한다. 별도의 4초 수레 연타도 실제 연타 상태의 목표 횟수를 읽어 안내한다. 재시도 횟수에 따라 목표가 바뀌는 연타는 바뀐 숫자를 사용한다. 이 분기들을 영상으로 검증했다고 표시하거나 기존의 8회 문 열기 영상을 대신 사용하지 않는다.

시간 표시의 초 값은 원작 업데이트 기준 60fps 환산이다. 설명 중 실제 시간이 지나도 판정 프레임은 차감되지 않는다. 기록 조각 맞추기 등 제한 시간 없는 퍼즐에는 이 안내를 붙이지 않았다.

## 변경 파일

- `js/plugins/DP_QTEGuide.js`: 시작 전 안내, 시간 정지, 원작으로 복귀, 입력 해제와 QTE 연결.
- `js/plugins.js`: 새 플러그인을 마지막에 활성화.
- `tutorial/index.html`: 게임에서 지정한 조작으로 바로 진입하고 설명으로 돌아가는 기능 추가. 단독 실행 방식은 유지.

맵 이벤트의 JSON과 기존 판정 플러그인은 수정하지 않았다. 업로드된 `data`는 배포 묶음에 그대로 포함한다. 플러그인 설정은 제공한 `plugins.js`에 이미 반영했다.

## 검증 범위

실제 게임을 Chromium 터치 환경에서 실행하고 원본 이벤트에서 가져온 Synrec 시작 명령 24개를 게임 인터프리터로 각각 실행해 검사했다. 검증을 위한 실행 위치만 격리하며 QTE 판정과 가상 터치 버튼은 실제 게임 코드를 사용한다. 자동화 도구의 통신 지연이 짧은 QTE 제한 시간을 소모하지 않도록 브라우저 가상 시계로 프레임을 진행하고 실제 터치 이벤트를 보낸다.

- 설명 중 QTE 생성·시간 진행·다음 이벤트 분기가 일어나지 않음.
- 준비 후 원래 버튼 순서로 성공하고 게임의 성공 분기가 실행됨.
- 잘못된 입력의 원작 시간 감점, 시간 초과 실패, 재시도 시 안내 재등장.
- 9개 연습의 정확한 연결과 복귀, 연습 성공이 게임 결과 스위치를 바꾸지 않음.
- 다섯 단일 신호의 중간 안내 중복 방지.
- 시작 확인 키를 길게 눌러도 첫 정답으로 처리하지 않음.
- 준비 중 창을 벗어나면 안전하게 설명으로 돌아옴.
- 두 수레 연타 API의 실제 목표 횟수 안내 및 터치 성공.

자동 검사 기록은 `게임연결-검증결과.json`에 있다. 게임 전체의 모든 이야기 분기를 처음부터 끝까지 재플레이한 결과는 아니며, 물리 태블릿과 iPad Safari 시험은 아직 하지 않았다.
